# IPClean-Scanner

یک اسکنر تعاملی Bash برای بررسی IPهای کاندید کلودفلر با **پروفایل واقعی VLESS/XHTTP در v2rayN**. اسکنر SNI، Host، Path، پورت، UUID، رمزگذاری VLESS، TLS fingerprint و ALPN را از لینک اشتراک v2rayN می‌خواند و هنگام آزمون فقط IP مقصد را جایگزین می‌کند.

## اجرای نخست

برای دریافت و اجرای نسخهٔ منتشرشده روی شاخهٔ `main`، این دستور تک‌خطی را در Bash اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/XiliService/IPClean-Scanner/main/scanner.sh)
```

در اجرای نخست، اسکریپت تلاش می‌کند دستور `cf-scanner` را نصب کند. در Termux مسیر `$PREFIX/bin`، در صورت داشتن دسترسی مسیر `/usr/local/bin` و در غیر این صورت مسیر `~/.local/bin` استفاده می‌شود. پس از نصب، از هر مسیری اجرا کنید:

```bash
cf-scanner
```

برای آزمایش نسخهٔ شاخهٔ کاری این نشست:

```bash
curl -fsSL https://raw.githubusercontent.com/XiliService/IPClean-Scanner/arena/0152535f-ipclean-scanner/scanner.sh -o scanner.sh && chmod +x scanner.sh && ./scanner.sh
```

## اسکن کانفیگ v2rayN

در منوی اصلی، گزینهٔ **1 — Quick Auto Scan** را انتخاب کنید:

1. در v2rayN روی سرور موردنظر راست‌کلیک و گزینهٔ **Copy Share Link** را انتخاب کنید.
2. در ترمینال WSL لینک `vless://...` را در ورودی مخفی اسکنر Paste کنید و Enter بزنید. لینک در صفحه نمایش داده نمی‌شود.
3. اسکنر خلاصهٔ غیرحساس کانفیگ را نشان می‌دهد؛ UUID و مقدار رمزگذاری را چاپ نمی‌کند.
4. اسکنر ۹۶ IP نمونه از رنج‌های کاندید و رسمی کلودفلر تولید می‌کند، دسترسی TCP را روی پورت همان پروفایل بررسی می‌کند و سپس با Xray Core یک اتصال واقعی VLESS/XHTTP می‌سازد.
5. برای تأیید عبور ترافیک، اسکنر یک درخواست HTTPS از داخل تونل به Cloudflare می‌فرستد. فقط IPهایی که این درخواست را با موفقیت کامل کنند در فهرست نهایی می‌آیند.

اسکن را زمانی اجرا کنید که WSL از همان اپراتوری استفاده می‌کند که می‌خواهید بررسی شود؛ برای مثال برای نتیجهٔ همراه اول، WSL باید از اینترنت همراه اول متصل باشد. نتیجه مربوط به همان اتصال فعلی است و تضمین چنداپراتوره نیست.

### Xray Core در WSL

اسکن واقعی به **Xray Core لینوکسی در WSL** نیاز دارد. اگر نصب نباشد، اسکریپت گزینهٔ دریافت نسخهٔ رسمی Xray Core از GitHub، بررسی SHA-256 و نصب آن در `~/.local/share/cf-scanner/` را نشان می‌دهد؛ یا می‌توانید مسیر یک فایل اجرایی Xray لینوکسی موجود در WSL را وارد کنید. این نصب یک‌باره است؛ فایل‌های پروفایل و گزارش اسکن موقت‌اند و هنگام خروج پاک می‌شوند.

نسخهٔ فعلی برای پروفایل‌های **VLESS + XHTTP + TLS** طراحی شده است. پروفایل‌های REALITY یا انتقال‌های دیگر را نمی‌پذیرد. اگر هستهٔ Xray نتواند لینک اشتراک را بخواند، اسکن را متوقف می‌کند و IP را موفق اعلام نمی‌کند.

## منوی اصلی

- **1 — Quick Auto Scan:** اسکن با لینک اشتراک واقعی v2rayN و آزمایش تونل XHTTP از شبکهٔ فعلی.
- **2 — Update Script:** بررسی `main`؛ اگر نسخهٔ آن جدیدتر باشد، بروزرسانی. در غیر این صورت، درخواست نام شاخه یا نشانی شاخهٔ سفارشی.
- **3 — Uninstall:** حذف دستور نصب‌شدهٔ `cf-scanner`.
- **0 — Exit:** خروج.

## حریم خصوصی و فایل‌های موقت

لینک اشتراک v2rayN شامل اطلاعات حساس مانند UUID و پارامتر رمزگذاری است. آن را در چت یا جایی عمومی ارسال نکنید؛ فقط در ورودی مخفی خود ترمینال Paste کنید. اسکریپت آن را در پوشهٔ موقت محافظت‌شده نگه می‌دارد (در صورت وجود از `/dev/shm` استفاده می‌کند) و هنگام خروج حذف می‌کند. فایل‌های موقت Xray نیز شامل اطلاعات پروفایل‌اند و پاک‌سازی می‌شوند. گزارش دائمی یا فایل فهرست IP ذخیره نمی‌شود. فایل اجرایی Xray Core در صورت نصب، برای استفاده‌های بعدی در مسیر یادشده باقی می‌ماند.

## نکات مهم

- این اسکنر **پینگ ICMP را معیار موفقیت نمی‌گیرد**؛ بعضی IPها به پینگ پاسخ نمی‌دهند ولی اتصال VLESS/TLS دارند. معیار اصلی، موفقیت درخواست HTTPS از داخل تونل VLESS/XHTTP است.
- هیچ IPای صرفاً به‌دلیل پاسخ TCP یا TLS «تمیز» اعلام نمی‌شود؛ عبور واقعی ترافیک تونل باید موفق باشد.
- رنج‌های بزرگ به‌صورت نمونه‌ای اسکن می‌شوند، نه کامل.
- IPهای Anycast کلودفلر ممکن است بر اساس اپراتور، مکان و زمان مسیر متفاوتی داشته باشند.
- اسکن فقط شبکهٔ فعلی را می‌سنجد. برای مقایسهٔ ایرانسل و همراه اول، اسکن را جداگانه روی هر اتصال اجرا کنید.
